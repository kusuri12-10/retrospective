# Claude Design 사용기

정말정말 이용하기 쉽고 간편하고 디자인도 잘 뽑아준다! 쓴지 얼마 안되서 꽤 만족스러운 디자인이 나왔다.

디자인 시스템 기능도 좋았다. 기존의 코드베이스나 디자인 시스템, 폰트 등을 업로드하면 해당 데이터를 클로드가 확인하고 디자인 시스템을 구축해준다.

기존에 디자인을 공부하거나 다루어 본 적이 없어서 기존 시안을 클로드에게 제공할 수는 없었지만, 폰트 정도만 제공해도 훌륭한 성능을 보여주었다. 클로드랑 같이 디자인 시스템을 처음부터 구축하는 걸로 볼 수 있겠다.

이미 만들어놓은 디자인 시스템을 가져다가 디자인을 할 수 있다. 화면 측면에서 채팅 형식으로 지시하거나, 또는 인라인 코멘트를 추가하여 특정 부분에 대해 클로드에게 직접 지시를 내릴 수 있다. 뿐만 아니라 직접 수정할 수도 있었다. 기존에 다른 AI를 이용하여 디자인 할 때와는 확연히 다른 점이었다. 정말 필요하다고 느낀 점이 모두 들어가있으니 확실히 디자인을 잘 모르는 나도 수월하게 디자인 할 수 있었다. 

이렇게 단점이라고는 찾기 힘든 클로드 디자인에게도 단점이 한 가지 있었다. 클로드의 고질적인 문제인, 토큰 제한 문제이다... 디자인 시스템 조금 만져보고 본격적으로 디자인을 하려던 찰나 토큰 한도에 도달해버렸다. 클로드 생태계는 claude pro로는 살아남기 힘든 것 같다... ~~그러나 그만큼 보장되는 성능에 굴복...~~

앞으로도 디자인이 필요할 경우 애용할 것 같다. 다만 여전히 아무것도 없이 "디자인 해줘" 하는 정도로는 기존에 AI가 디자인 한 것 같은 그 느낌에서는 벗어날 수 없었고, 계속해서 사람이 지시하고 리뷰하는 과정이 필요하다고 느꼈다.
