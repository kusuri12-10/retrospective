### 4. 스타트업

예비창업패키지, 초기창업패키지, 창업중심대학 -> 지원받을 수 있음

심사에서 제품 이야기는 생각보다 많이 안하고. 어떤 문제를 어떻게 해결했는지, 이게 사업성이 있는지를 많이 봄
: 동기, 시장, 해결책, 팀 -> 사업 계획서에 시간을 많이 쓸 것

코드 조금씩 쓰면서 소비자를 만나볼 것

### 5. 투자

SEED는 매출과 재품이 있어야 함

프리시드 -> SEED -> 시리즈A ... 기업상장

SEED = 매출 + 제품

투자 미팅은 8개월전부터 준비하고, 꼼꼼히 챙길 것

빨리 받기 > 잘 받기 (주관적인 입장), 빨리 협상하고 제품 만들기

1-2억쯤 투자받으면 정부에서 8억을 지원해줌 -> 그만큼 쓸 수 있는 카드가 많다

단, 투자 받는게 목표가 되면 안됨
